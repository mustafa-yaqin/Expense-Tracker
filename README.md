# Expense Tracker

A simple expense tracker built with React and React Router.

![Expense Tracker screenshot](screenshot.png)

## Features

- See your balance, total income and total expenses
- Add a transaction on its own page
- Delete a transaction
- Data is saved in the browser with localStorage

## Pages

| Path   | Page                                     |
| ------ | ---------------------------------------- |
| `/`    | Balance summary and list of transactions |
| `/add` | Form to add a new transaction            |

## Tech

- React
- React Router
- Vite

## Run locally

```
npm install
npm run dev
```

## Build

```
npm run build
```
